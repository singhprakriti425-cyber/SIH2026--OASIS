# OASIS — Climate-Responsive Passive Shelter Design Lab 🌍

OASIS is a browser-based conceptual design and analysis platform for planning passive shelters in disaster-prone and remote locations.

The platform helps users explore site-specific shelter designs by combining climate data, material selection, enclosure geometry, and thermal analysis.

## ✨ Features

* 🌤️ Live climate data lookup
* 🏠 Passive shelter configuration
* 🧱 Material selection
* 📐 Enclosure geometry exploration
* 🌡️ Indoor temperature and thermal analysis
* 📊 Interactive analysis dashboard
* 💾 Conceptual design outputs
* 🧮 Transparent single-zone RC thermal model
* 🌬️ Airflow and ventilation design intent
* 📄 Technical project documentation

## 💡 Problem

Generic emergency shelters may not perform well across different climatic conditions. They can lead to thermal discomfort, higher energy requirements, and durability challenges.

OASIS explores a site-specific approach to passive shelter design by considering local climate conditions during the conceptual design process.

## 🚀 Solution

OASIS uses climate information and design parameters to provide an interactive environment for exploring shelter configurations and estimating thermal performance.

The platform combines:

* Climate data
* Shelter geometry
* Material properties
* Thermal calculations
* Design visualization

## 📊 Thermal Analysis

OASIS uses a simplified single-zone RC thermal model to estimate heat transfer and indoor temperature behavior.

The model is designed to keep the analysis transparent and understandable while supporting early-stage conceptual shelter design.

## 🔬 Engineering Workflow

The project also includes an ANSYS MAPDL reference input file that can be used as a starting point for further engineering analysis.

## 🎯 Project Goal

The goal of OASIS is to support climate-responsive and energy-conscious passive shelter planning, especially for disaster management and remote locations.
